# mynatalnotes.com

The Natal Notes website: the 12 zodiac Daily Journals, a sidereal sign finder, and a page per sign.

- Edit `content/journals.yml` (journals, Amazon links, sign copy) and `content/site.yml` (settings, socials).
- Run `pip install pyyaml && python3 build.py` to rebuild `docs/`, which GitHub Pages serves.
- Never edit `docs/` by hand.
